Зачем ещё один плеер?
Мне не хватало большинства главных фишек, поэтому я воспользовался принципом: 

Хочешь сделать хорошо - сделай сам.


Большинство плееров под Cardputer упираются в потолок 256–2 000 треков, ломаются на кириллице или подвисают при перемешивании. В MP3PLUS я выжал из 320 КБ доступной SRAM чипа ESP32-S3 всё, что позволяет железо:

До 4 096 треков в одной папке. Имена индексируются в лёгкий служебный файл на microSD (/.mp3plus.idx) + горячий RAM-кэш на 16 строк. Проверено вживую на реальной папке ~1 000 треков открывается и листается без тормозов.
Мгновенный Shuffle за 0 мс (S) еразрушающее перемешивание Фишера–Йейтса прямо в ОЗУ. Включил и треки идут вперемешку; выключил и моментально вернулся к исходному порядку без изменения файлов.
Форматы: MP3, M4A (AAC), WAV. пПавное двухъядерное декодирование на Core 0 без PSRAM.
Аппаратный Amp Boost (A) 100% / 150% (+6 дБ) / 200% (+11 дБ) напрямую через ЦАП ES8311 на Cardputer-Adv, плюс автоматическое переключение на разъём 3.5 мм.
2-в-1 в одном .bin сам определяет M5Stack Cardputer-Adv и оригинальный M5Stack Cardputer.
5-цветный визуализатор с AGC (V). Реальный 3-полосный DSP с автоусилением: столбики бодро реагируют на музыку даже на тихой громкости (03). Режимы: BARS, PEAK, WAVE, OFF.
Полная поддержка кириллицы (UTF-8). Русские названия треков и папок без кракозябр в 3 размерах шрифта (G).
Карманный режим (боковая кнопка G0) отдельно управление с выключенным экраном: 1× Пауза/Пуск, 2× След. трек, 3× Пред. трек. (Пипец как удобно в кармане)
Экономия батареи и комфорт - 6 цветовых тем (T), ровная яркость 20%–100%, автовыключение экрана, режим 160 МГц Eco во сне и автосохранение настроек в NVS.

Быстрая установка (через M5Launcher)
Скачай последний .bin
Скопируй его на FAT32 microSD-карту (например, /MP3PLUS.bin).
Запусти M5Launcher на Cardputer, выбери .bin и нажми Install (или Run).
Кидай папки с музыкой куда угодно на SD и жми F для выбора папки.
Управление
Клавиша	Действие
Enter / Space	Пуск / Пауза / Открыть папку (Space в списке папок запускает всю папку)
; / .	Вверх / Вниз по списку (удержание - быстрая прокрутка)
N / B	Следующий / Предыдущий трек
/ / ,	Перемотка вперёд / назад (5с или 10с, работает удержание)
[ / ] или - / =	Громкость тише / громче (0–21)
A	Аппаратный буст громкости (100% / 150% / 200%)
S	Мгновенный временный Shuffle
L	Режим повтора (NORM / RP1X / RPINF / RPALL)
R	Реверс порядка воспроизведения (FWD ↔ REV)
F	Браузер папок
T / V / G	Тема / Визуализатор / Размер шрифта
M / I / Esc	Настройки / Подсказка по клавишам / Назад
G0 (сбоку)	Карманный режим: 1× Пауза · 2× След. · 3× Пред.
